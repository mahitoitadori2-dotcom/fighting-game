# Universal Beatdown

2D platform fighter in Godot 4.7 (GDScript, Compatibility renderer, also exported for Web / iPhone).

**Current status, bugs, problems and plans:** [vault/Universal Beatdown - Progress & Plans.md](vault/Universal%20Beatdown%20-%20Progress%20&%20Plans.md). Read it first; after any change to the game, update it (use the `update-vault` skill).

## Basics
- Godot editor: `C:/code/Godot_v4.7.2-stable_win64.exe`
- Story Mode: `scripts/story/`. Enemies: `scripts/enemies/`. Sound: `scripts/audio/SoundManager.gd`
- Web build: Project → Export → Web (writes `web/play/`); test locally with `node tools/serve.js web 8060`
